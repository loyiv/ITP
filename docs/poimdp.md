## POIMDP Boundary (Implementation Notes)

Reference: *Imagine-then-Plan: Agent Learning from Adaptive Lookahead with World Models* ([arXiv:2601.08955](https://arxiv.org/pdf/2601.08955)).

### What we treat as “POIMDP” in code

In this release, the POIMDP concept is expressed as a **software boundary**:

- **Observable stream**: task instruction + interaction history (the “present”).
- **Imaginable stream**: \(K\)-step foresight generated by the world model (the “future”).

The key ITP_I orchestration is implemented as:

`select K -> imagine -> reflect_and_act`

and lives in `itp/orchestrator.py`.

### Interfaces

- `PolicyModel.decide_k(task, history, max_k) -> (k, raw)`
- `WorldModel.imagine(history, k) -> (foresight, raw)`
- `PolicyModel.reflect_and_act(task, history, foresight, admissible_actions) -> (reflection, thought, action, raw)`

Prompt templates are kept under `prompts/` to match Appendix B.1.
