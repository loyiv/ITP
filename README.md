## 💡 Overview

This repository is a **public-release packaging** of the research code for **Imagine-then-Plan (ITP)**, proposed in *Agent Learning from Adaptive Lookahead with World Models* ([arXiv:2601.08955](https://arxiv.org/pdf/2601.08955)).

Modern LLM agents often behave **reactively**: they act based on the current observation and short history, which can be brittle for **long-horizon** tasks. ITP addresses this by introducing a learned **textual world model** and an **adaptive lookahead** mechanism, enabling the agent to **mentally rehearse** possible futures before committing actions in the real environment.

### 🧠 POIMDP: Decision-Making with Imagination

ITP formalizes agent reasoning as a **Partially Observable and Imaginable MDP (POIMDP)**, where the agent conditions its decision on:

- the current observable state (textual observation) \(s_t\), and  
- an imagined \(K_t\)-step future trajectory \(\hat{\tau}_t^{(K_t)}\) generated by the **world model**.

Concretely, at time step \(t\), the agent and world model interact inside a “mental sandbox” for \(K_t\) steps to obtain foresight:
\[
\hat{\tau}_t^{(K_t)} = \{(\hat{a}_{t+i}, \hat{s}_{t+i+1})\}_{i=0}^{K_t-1}.
\]
The policy then chooses the next action by fusing **present evidence** with **imagined consequences**, improving long-term credit assignment and reducing irreversible mistakes.

### 🧩 Two Instantiations: ITP\_I and ITP\_R

ITP is instantiated in two complementary variants:

#### 🔍 ITP\_I (Training-free, In-Imagination Learning)

**ITP\_I** is designed to enhance an LLM agent *at inference time* without parameter updates. Both the agent policy and world model remain frozen, and the agent runs a three-stage **Imagine-then-Plan** procedure at each step:

1. **Adaptive horizon selection**: decide \(K_t \in \{0,1,\dots,K_{\max}\}\) from the task instruction + current state.  
   This allocates deeper foresight to high-stakes decisions while keeping trivial steps efficient.
2. **World-model imagination**: invoke the world model to roll out \(K_t\) steps and obtain \(\hat{\tau}_t^{(K_t)}\).
3. **Reflect-then-act**: instead of directly executing the first imagined action, the agent **reflects** on \(\hat{\tau}_t^{(K_t)}\) to assess goal progress, detect conflicts/bottlenecks, and perform self-refinement before producing the real action \(a_t\).

This transforms passive reaction into proactive deliberation, improving success rates with controllable cost.
